# S-HOUSE in Awaji

淡路島の架空の宿泊施設「S-HOUSE」のサンプルサイトです。

## 技術スタック

- **HTML5** - セマンティックなマークアップ
- **CSS3** - レスポンシブデザインとアニメーション
- **Bootstrap 5.3.0** - モダンなUIフレームワーク
- **Swiper.js** - 画像スライダー
- **SCSS** - CSSプリプロセッサー

## プロジェクト構造

```
S-HOUSE/
├── index.html          # メインページ
├── 404.html           # エラーページ
├── CSS/
│   ├── style.css      # コンパイル済みCSS
│   ├── style.css.map  # ソースマップ
│   └── style.scss     # SCSSソースファイル
├── IMG/               # 画像・動画ファイル
│   ├── *.webp         # 最適化された画像
│   ├── *.svg          # ベクター画像
│   └── *.mov          # 動画ファイル
├── vercel.json        # Vercel設定ファイル
├── package.json       # プロジェクト設定
└── README.md          # このファイル
```

## セットアップと開発

### 前提条件
- Node.js (v14以上)
- npm

## レスポンシブデザイン

このウェブサイトは以下のブレークポイントでレスポンシブ対応しています：

- **デスクトップ**: 1200px以上
- **タブレット**: 768px - 1199px
- **モバイル**: 767px以下

## デザインシステム

### カラーパレット
- **プライマリ**: #1A1A1A (ダークグレー)
- **セカンダリ**: #41badf (アクセントブルー)
- **背景**: #ffffff (ホワイト)
- **テキスト**: #1A1A1A (ダークグレー)

### フォント
- **日本語**: YuGothic, Helvetica Neue
- **英語**: Inter, Open Sans, Sora
